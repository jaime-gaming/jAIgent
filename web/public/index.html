    Sessions
    
        
    
          Every conversation jAIgent has saved on this machine, from the terminal
          and from here. Opening one loads its transcript.
        
    
        
    
      
    
    
    

    
    
      
    
        
    Files
    
        
    
          The workspace on this machine. Opening a file edits the real one: what
          you save is written to disk here, and a checkpoint is taken first, so
          jaigent undo in the terminal reverts it exactly as it
          reverts a change the agent made.
        
    
        
    
        
    

        
    
          
    
            
            
            
            
            
            
          
    
          
    
            
            
            
          
    
          
          
          
    
        
    
      
    
    
    

    
    
      
    
        
    Checkpoints
    
        
    
          Snapshots jAIgent takes before it writes to a file, so a change can be
          undone. Restoring still happens in the terminal, with
          jaigent undo. The panel reads; it does not reach in.
        
    
        
    
      
    
    
    

    
    
      
    
        
    Settings
    
        
    
          Everything this panel runs against, grouped, each with the value it has
          right now and the exact flag or environment variable that changes it.
          Nothing is edited in the browser: to change one, restart
          jaigent web with the flag shown, or set the variable. Keys
          are masked before they leave the server, so a secret reads as
          set or unset, never as itself.
